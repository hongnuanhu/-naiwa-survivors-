# GitHub 上传准备

本次只本地整理，没有新建、绑定或上传 GitHub 仓库。

建议仓库名：naiwa-survivors

建议描述：支持手机触屏与电脑键盘的十二波自动攻击生存游戏，使用 TypeScript、Phaser 和 Vite。

建议首次提交说明：整理奶蛙幸存者源码、使用教程、验证记录与发布脚本

## 上传前需确认

1. 目标仓库完整地址，以及公开 / 私有状态；确认是新仓库还是已有内容的仓库。
2. 有目标写权限的 GitHub 登录身份；不要把令牌、密码写到项目、ZIP、README 或远程 URL。
3. 对公开上传或向别人分发，先确认图片、音乐、参考形象与代码许可。当前 LICENSE.md 不是开源授权；未知许可素材需授权或替换。私有仓库不自动解决再分发权利。

## 推荐上传方式

将源码 ZIP 解压到独立目录，在那里初始化新仓库，避免带入现有托管 Git 历史、远程地址与站点身份。上传 src、public、docs、scripts、配置、锁文件和许可说明。不要上传 node_modules、dist、releases、.release-stage、.openai、.env、凭据、浏览器状态与个人存档。

.gitignore 不会清除已跟踪文件和历史秘密，已有仓库必须另查暂存区和历史。本次没有删除原 .git 或改动旧站点配置；发布包按白名单排除它们。确认目标后再执行 remote / push。

可把源码 ZIP、运行 ZIP、SHA256SUMS.txt 作为 Release 附件。源码包供修改构建，运行包已含静态页面，需 Node.js 或 HTTP 托管；两包素材许可限制相同。
