# 奶蛙幸存者使用教程

## 解压与启动

请先完整解压 ZIP，不要在压缩软件内双击 HTML。安装 Node.js 24（要求 ≥22.12）。

- 源码包：在 package.json 所在目录运行 npm ci，再 npm run dev，打开终端显示的 http://127.0.0.1:5173/。
- 运行包：在解压目录运行 node scripts/serve.mjs，打开 http://127.0.0.1:4173/。无需 npm ci。
- 源码正式预览：npm run build，再 npm start。修改源码后必须重新构建才会更新此地址。
- 终端保持开启；Ctrl+C 停止服务。项目无需账号、API Key 或 .env。

## 开始一局

1. 等待加载完成，开始按钮可点击。
2. 选奶蛙（均衡）、美团鼠（近战耐打但移动稍慢）或奶蛋（范围攻击，生命较低）。新手建议奶蛙和简单难度。
3. 选择简单、标准、困难或自定义；自定义的敌人生命、伤害、移速可设为 50%～150%。只对新局生效，继续旧局不会更改旧难度。
4. 点击开始。若有旧存档，确认新局将覆盖它；保留旧进度则点继续冒险。
5. 手机横屏并关闭系统方向锁定。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD 或方向键，斜向速度归一化 | 战场任意空白处按住并拖动，松手停止 |
| 攻击 | 自动，空格不是攻击键 | 自动，没有攻击按钮 |
| 暂停 / 继续 | Esc 或右上角暂停按钮 | 右上角暂停，再点击继续 |
| 菜单与商店 | 鼠标点击 | 触屏点击、滑动商店 |

尽量保持移动，绕开接触敌人、弹丸和地面预警，靠近掉落物拾取。顶部显示生命、经验、波次、计时和奶币。队长 / 魔王出现时显示血条。

切后台或失去焦点会暂停战斗。手机转竖屏会提示横屏并暂停，转回后点击继续。“摇杆位置提示”设置只改变提示，任意空白处仍可移动。声音、音乐、震屏、伤害数字可在设置中分别开关。

## 掉落、升级和商店

非治疗材料增加奶币和经验，治疗掉落恢复生命。普通波结束时结算未拾取的非治疗材料。等级提升产生待选强化，在波次结束后从三个选项中选择；多次强化需逐个选完，然后购物。

商店显示四件武器或道具。奶币不足不能买，已售商品不能重复买。菱形按钮锁定 / 解锁未购商品，锁定商品跨刷新和下一波保留；刷新花奶币，同一轮重复刷新费用提高。

武器六槽、四级品质：普通 → 精良 → 稀有 → 史诗。点击背包武器查看操作：

- 两件同类同品质且非史诗的武器，可点“合成同级武器”，变成一件高一级武器。
- 有空槽时，买重复武器会占新槽；满槽时，只有匹配同类同级且可升级的商品能购买并自动合成。
- 回收可返还部分奶币，但不能回收最后一把武器。被动道具无法像武器一样回收。

购物后点击底部“进入第 N 波”；下一波恢复 20% 最大生命，不是全回血。商店和强化不消耗战斗计时。

## 胜负条件

普通波倒计时归零即完成，不必清空敌人。第六波出现队长，也不强制击败。第十二波存活至倒计时结束，或提前击败魔王，即通关。生命归零即失败，致命伤害不会被同帧拾取治疗抵消。

十二波倒计时总计 590 秒，购物强化另计，预期一局约 10～15 分钟；最终波击杀魔王可提前结束。

## 复活与重新开始

死亡后点“暗号复活”，输入 **szx牛逼**，确认后再点继续。szx 必须小写，允许首尾空格。每局一次，恢复满血，保留装备和本波剩余时间，获得 3 秒保护。输错或取消不耗次数；刷新不恢复次数。暗号是公开玩法，不是账户安全措施。

失败或通关界面点“重新开局”，沿用本局角色与难度从第一波开始，等级、装备、奶币和复活次数重置。想换角色和难度，返回营地再选择。

游戏中重开：暂停 → 保存并返回营地 → 选角色和难度 → 开始 → 确认新开一局。不会自动替你保留第二份旧局。

## 存档和注意事项

战斗约每 3 秒保存，交易、暂停与波次切换也保存。突然关闭可能丢失最后数秒。同浏览器同地址重新打开后，营地“继续冒险”恢复本局，战斗存档恢复后先处于暂停状态。

存储受限会提示，当前标签页仍可保留内存进度，关闭后不保证恢复。清站点数据会一起清掉进度、设置和最好成绩。换域名、端口、协议或浏览器（包括微信与系统浏览器之间）都可能是另一份存档。没有云同步、备份服务或竞技防作弊。存档不会写入项目文件，也不随 ZIP 分享。

## 手机与微信

同 Wi-Fi：运行包在电脑运行 node scripts/serve.mjs --host 0.0.0.0，手机打开 http://电脑局域网IP:4173/。源码开发用 npm run dev -- --host 0.0.0.0，端口 5173。检查防火墙允许专用网络访问。不要将 localhost / 127.0.0.1 发给朋友作为公网链接。

异地分享需要部署 HTTPS 静态站点，上传 dist 的全部内容至域名根目录。当前 /assets/ 资源路径不能直接用于 /仓库名/ 子路径。微信访问、国内网络、软键盘和音频恢复仍需安卓与 iPhone 真机测试。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| node / npm 找不到 | 安装 Node.js 后重新打开终端，用 node --version 检查。Windows 的 npm.ps1 被策略阻止时使用 npm.cmd |
| 缺少 dist/index.html | 源码先 npm ci、npm run build；运行包完整解压，保留 dist 和 scripts 的位置 |
| 端口被占用 | 运行包加 --port 4174；开发服务 npm run dev -- --port 5174。换端口也会换浏览器存档 |
| 双击 HTML 白屏 | 用 HTTP 服务，不支持 file:// |
| 加载失败 / 开始不可用 | 确认素材完整、没有误部署到子路径，查看网络面板失败请求，重新解压或部署全部 dist |
| 手机打不开 | 同 Wi-Fi、电脑 IP、host 参数、端口、防火墙都要正确；不能用电脑的 127.0.0.1 |
| 没声音 | 点击开始 / 继续触发声音，检查游戏设置和系统音量；微信音频限制还需真机确认 |
| 商品买不了 | 检查奶币、是否售出、是否满槽；满槽必须匹配可合成武器 |
| 存档消失 | 检查浏览器、地址与端口，是否清数据或开了无痕；无服务器备份 |
| 发热卡顿 | 可关震屏、伤害数字并减少后台应用；未完成真机长期性能测试 |
| QA 浏览器起不来 | 脚本默认要求已安装 Microsoft Edge；其他平台需安装 Edge 或自行调整 Playwright channel。普通玩家无需运行 QA |
| 能直接公开全部素材吗 | 目前没有齐备的再分发授权，须授权或替换；公开可访问不等于授权，详见 ASSETS.md |
